# OWASP Juice Shop Top 10 Lab

This repository contains a theory-based application security research report mapping representative OWASP Juice Shop v20.2.0 challenges to the OWASP Top 10:2025.

## Contents

- **OWASP Juice Shop Top 10 2025 Mapping.docx** — the complete seven-page report, including the mapping matrix, detailed findings, defensive controls, category boundaries, and a safe local validation plan.

## Scope

No vulnerable application instance was deployed and no exploits were executed for this report. The crosswalk is based on official OWASP documentation and the official Juice Shop challenge catalog. Because OWASP has not published a formal one-to-one crosswalk between the two taxonomies, each mapping is identified as direct, strong, or partial.
